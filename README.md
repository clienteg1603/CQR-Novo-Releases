# CQR Novo — Releases

Repositório público usado exclusivamente para distribuir versões do **CQR Novo**.

Os usuários do programa não precisam de acesso ao código-fonte privado. O aplicativo consulta as Releases deste repositório para verificar novas versões.

Cada Release deverá conter:

- `CQR_Novo_Update_vX.Y.Z.zip`
- `release-manifest.json`

O manifesto inclui o SHA-256 do pacote para validação de integridade antes da instalação.

> O código-fonte permanece no repositório privado `clienteg1603/CQR-Novo`.
